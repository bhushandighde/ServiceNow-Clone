# ServiceNow Clone

Enterprise Ticket Management System built using ASP.NET Core 8 and Clean Architecture.

## Features

- JWT Authentication
- Clean Architecture
- CQRS with MediatR
- Repository Pattern
- AutoMapper
- FluentValidation
- Global Exception Handling
- Serilog Logging
- Docker & Docker Compose
- SQL Server
- Swagger

## Tech Stack

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- MediatR
- AutoMapper
- FluentValidation
- Serilog
- Docker

## Run Locally

```bash
docker compose up --build
```
